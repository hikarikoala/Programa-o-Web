# 🌐 Programação Web

Repositório dedicado ao aprendizado, prática e documentação de conceitos de desenvolvimento web, integrando interfaces interativas e pequenos jogos.

---

### 🎯 Objetivos

* Praticar a estruturação semântica com **HTML5**.
* Desenvolver estilização e layouts visuais com **CSS3**.
* Implementar lógica e dinamismo com **JavaScript**.
* Construir protótipos e jogos simples baseados em navegadores.
